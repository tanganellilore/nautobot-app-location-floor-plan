# Frequently Asked Questions

## Why is there no map for a child Location?

The child must own a map or be explicitly placed on an ancestor map. Location Floor Plan does not infer focus from an intermediate parent placement.

## Why did save return 409?

The map revision changed. Reload and save again with the latest revision.

## Why was my background rejected?

Check file type, byte size, pixel count, dimensions, and SVG safety restrictions.
