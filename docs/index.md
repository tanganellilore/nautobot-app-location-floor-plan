# Location Floor Plan Documentation

Location Floor Plan (`location_floor_plan`) provides interactive physical hierarchy maps for Nautobot Locations and Racks. It stores map canvases and placement geometry while Nautobot remains the source of truth for Locations, Racks, Devices, and permissions.

Start with:

- [Install and Configure](admin/install.md)
- [Getting Started](user/app_getting_started.md)
- [Using the App](user/app_use_cases.md)
- [Upgrade](admin/upgrade.md)

Key facts: Nautobot `>=3.2.3,<3.3`, Django 5.2.17, Python 3.10-3.14, package `location-floor-plan`, app package `location_floor_plan`, Leaflet 1.9.4, Geoman Free 2.20.0.
